Airline Ticket Prices vs Fuel Costs Analysis

DVA Capstone · 2026
Tableau · Python · ARIMA · K-Means · OLS Regression
  • Built a Python ETL pipeline integrating 6 aviation datasets (fuel prices, fares, surcharges, route costs, financial metrics, conflict events) with automated cleaning and feature engineering.
  • Performed statistical analysis — OLS regression (R² ~0.08), Pearson correlation (r ~0.28), Welch's t-test (p < 0.05), ARIMA forecasting, and K-Means clustering revealing 3 pricing regimes.
  • Designed a 4-view interactive Tableau dashboard (Executive Overview, Operational Drill-down, Fuel Impact, Conflict Analysis) with dynamic filters for conflict phase, airline type, and route class.
  • Key finding: Fuel-to-fare pass-through is partial, not 1:1 — demand conditions and geopolitical events influence pricing more than fuel cost alone.
